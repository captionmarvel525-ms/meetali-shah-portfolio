## 🛠️ Tech Stack
- HTML5
- CSS3 (custom properties, Flexbox, 3D transforms)
- JavaScript (vanilla, no frameworks)
- three.js — powers the animated particle network in the hero

- Scroll-in animations on every section
- Interactive 3D constellation background in the hero that reacts to the mouse
- 3D tilt effect on the profile photo and on project/achievement cards
- Hover effects throughout
